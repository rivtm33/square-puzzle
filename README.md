# 四角をつくる

ポリオミノ（1〜5マスのブロック）を敷き詰めて、盤面の正方形をぴったり埋めるパズル。
実機のボードゲーム（ブロックス風の透明ピース＋ルーレット）をデジタル化したものです。

React + TypeScript + Vite + Tailwind CSS。ゲームロジックはすべて自前実装で、外部ゲームライブラリなし。

## 動かす

```bash
npm install
npm run dev
```

```bash
npm test
```

## 遊びかた

- トレイのピースをタップして選ぶと、**置く場所のプレビューが盤面に出たままになる**。盤面をタップ（またはマウスなら移動）でプレビューを動かし、離すと確定
- トレイからそのまま盤面へドラッグしてもOK（指の少し上が狙った位置になる）
- 「回転」「反転」で向きを変える。回してもプレビューの位置は動かない
- 置いたピースをタップすると手元に戻る
- 「ヒント」は今の盤面から解を1つ探して、正解の1手を代わりに置く。詰んでいる場合は教えてくれる

盤面からはみ出す位置を狙っても、**プレビューが盤面内に丸められ、その見えている場所にそのまま置かれる**。
プレビューと実際の配置先は必ず一致する（どちらも `clampAnchor` を通している）。

### キーボード操作

試行錯誤（選ぶ→回す→少し動かす）はキーボードのほうが速い。ゲーム中に `?` で一覧が出る。

| キー | 動作 |
| --- | --- |
| `←` `↑` `→` `↓` / `WASD` | カーソルを動かす |
| `R` | 回転 |
| `F` | 反転 |
| `Enter` / `Space` | そこに置く（クリア後はつぎのレベルへ） |
| `1`〜`9` | 手持ちのピースを番号で選ぶ |
| `Q` `E` / `Tab` | 前後のピースへ |
| `Backspace` | カーソルの下のピースを手元に戻す |
| `Z` | ひとつ戻す |
| `H` | ヒント |
| `Esc` | 選択をやめる |
| `?` | キー一覧 |

### モード

| モード | 内容 |
| --- | --- |
| ノーマル | レベル1から順に。4×4 → 5×5 → 6×6 と広がる |
| タイムアタック | 180秒で何面クリアできるか |
| チャレンジ | ルーレットで出た種類のピースしか置けない縛り |

### 進捗ときろく

- クリアしたレベル・ベストタイム・ヒント回数を **localStorage に保存**する。次に開いたときは続きから
- タイトルの「レベルをえらぶ」から全30レベルを一覧。ひとつ前をクリアすると次が開く
- **同じレベル番号なら毎回おなじ問題**（レベル番号からシードを決めている）。だからタイムを縮める遊び方ができる
- タイトルの「きろく」に、タイムアタックのベスト5とレベル別ベストタイムのランキング
- ★ はヒントを1回も使わずにクリアした印

保存先は `localStorage` の `square-puzzle:progress:v1`。壊れたデータが入っていても
`parseProgress` が形を検証して捨てるので、起動できなくなることはない。
localStorage が使えない環境（プライベートモードなど）でも、記録が残らないだけで普通に遊べる。

ルーレットはノーマル／タイムアタックでは非表示。ヘッダーの 🎡 で切り替えられる（チャレンジでは常時表示）。

## 構成

```
src/
  lib/            コアロジック（UIに依存しない純粋な関数群）
    pieces.ts     ブロックス21種のピース定義とルーレットのカテゴリ分類
    geometry.ts   normalize / rotate / flip / allOrientations
    board.ts      canPlace / place / remove / isSolved など盤面操作（イミュータブル）
    solver.ts     バックトラッキングのソルバー
    levelgen.ts   レベル生成とヒント
    rng.ts        シード可能な乱数
  game/
    state.ts      useReducer のゲーム状態
    storage.ts    進捗・記録の保存（localStorage を触るのは load/save だけ）
    colors.ts     ジュエル4色
  components/     UI
```

### ソルバーの考え方

「残っている空きマスのうち、走査順（上→下、左→右）でいちばん最初のマスを必ず埋める」方式。
そのマスは必ずどれかのピースの**走査順で最初のマス**になるので、位置の候補が1ピースの向きにつき1通りだけに絞れる。
これが効いて 6×6 でも数ミリ秒で解ける。

さらに、空きマスの連結成分ごとにサイズを調べ、
「手持ちピースのサイズの組み合わせでは作れないサイズの塊」ができた時点で枝刈りする。

### レベル生成

空盤面を難易度の重み付きでランダムに敷き詰め、**その構成をそのまま手持ちピースとして出題**する。
完成状態から逆算しているので、解けないレベルは原理的に出ない（生成時にソルバーでも検証している）。

難易度は使うピースの大きさで調整：easy は 2〜3マス中心、hard はペントミノ中心。
